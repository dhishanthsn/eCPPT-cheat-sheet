# Contributing

Thank you for helping improve this eCPPT study repository.

## Reporting an issue

If you find an incorrect command, outdated explanation, broken link, or unclear section, open an issue and include:

- The file and heading.
- What appears incorrect or unclear.
- The corrected behaviour or a reliable reference, if available.
- The operating-system or tool version, where relevant.

## Updating notes

- Keep explanations technically accurate and focused on the topic.
- Explain what a command does, its important options, and when it is useful.
- Include safe, reproducible examples where possible.
- Identify prerequisites and version-specific behaviour.
- Avoid duplicate explanations; link to an existing section instead.
- Use clear headings, fenced code blocks with language identifiers, and concise tables where they improve readability.
- Do not include credentials, private data, real target information, or unauthorised access instructions.

## Responsible use

All examples must support education and authorised security testing. Do not contribute secrets, personal data, or material that encourages testing systems without permission.
