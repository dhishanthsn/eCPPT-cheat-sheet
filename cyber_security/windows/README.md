## Suggested study order

1. Build a foundation in Windows architecture, users, groups, permissions, processes, services, and the file system.
2. Learn CMD and PowerShell syntax and common administration commands.
3. Practise host and domain enumeration in a controlled lab.
4. Understand common security weaknesses and how to validate findings.
5. Use the consolidated notes for revision and cross-reference the command guide during practice.

**Practice safely:** Run enumeration and assessment commands only on systems you own or are explicitly authorised to test.
