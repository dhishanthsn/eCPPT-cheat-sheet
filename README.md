# eCPPT Cheat Sheet

A structured, practical knowledge base for preparing for the **INE Certified Professional Penetration Tester (eCPPT)** certification.

The repository is organised as a set of study notes, command references, and practical workflows. Its goal is to make revision easier while keeping related topics easy to navigate.

| [Linux](./cyber_security/linux/README.md) | Linux study material | In progress |

- [All-in-One Windows Notes](./cyber_security/windows/all_in_one_windows.md) — consolidated Windows reference.
- [Windows PowerShell and CMD](./cyber_security/windows/WINDOWS_POWERSHELL.md) — command-line learning path from basic to advanced.

## How to use this repository

1. Start with the relevant topic index.
2. Work through concepts in order rather than memorising commands in isolation.
3. Practise commands in a local lab or another environment where you have explicit permission.
4. Keep personal lab observations separate from general reference material.
5. Revisit the notes during revision and verify commands against the target system and tool version.

## Scope and responsible use

These notes are intended for education, certification preparation, and authorised security testing only. Test only systems that you own or have explicit permission to assess. The material is a study aid, not a substitute for hands-on practice or the official certification objectives.
